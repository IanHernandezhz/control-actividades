# Parte 3: Interpretacion de comandos

## 1. Analiza

1. \git status\: Muestra el estado actual del repositorio 
2. \git add README.md\: Mueve el archivo README.md al area de preparacion.
3. \git commit -m Actualiza documentacion: Guarda una instantanea local de los cambios en el historial con un mensaje descriptivo.
4. \git push\: Envia los commits locales al repositorio remoto en GitHub.

## 2. Identifica que falta

### Caso A
* **Operacion que falta:** \git commit -m "mensaje" y el URL\
Funcion: Registra y guarda de forma permanente los cambios en el historial local de Git antes de enviarlos al servidor.
### Caso B
* **Operacion a utilizar:** \git clone\
Explicacion: Descarga por primera vez la copia completa de un repositorio de GitHub a tu computadora local.
### Caso C
* **Operacion a utilizar:** \git pull\
Explicacion: Descarga e integra los ultimos cambios del repositorio remoto hacia tu repositorio local que ya esta iniciado.
